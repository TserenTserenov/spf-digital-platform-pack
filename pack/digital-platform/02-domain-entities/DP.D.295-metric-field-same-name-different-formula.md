# DP.D.295 multiplier_estimated ≠ «Мультипликатор дня»

| Аспект | multiplier_estimated | «Мультипликатор дня» |
|--------|----------------------|------------------------|
| Когда вычисляется | Автоматически при событии сессии | Вручную при закрытии дня |
| Источник | WakaTime/session-hours снимок ledger | Бюджет/WakaTime, ручной пересчёт |
| Владелец формулы | Нет единого — разные подсистемы | Нет единого — разные подсистемы |

## Правило

Одноимённые или похоже названные поля метрики без единого владельца формулы, живущие в разных подсистемах, расходятся молча — иногда в разы — пока их явно не сверить рядом. Ни один потребитель обычно не сверяет их между собой, потому что оба выглядят как «тот же мультипликатор».

## Тест

«Два поля с похожим названием вычисляются в разных местах кода без общего источника формулы?» Да → не считать их взаимозаменяемыми без явной сверки; фикс — не переименование к общему имени, а разведение по разным полям с явным приоритетом одного над другим (например, отдельное `multiplier_final` с приоритетом над авто-снимком).

## Применимо к

Любая система с несколькими подсистемами, вычисляющими метрику с похожим смыслом/названием (авто vs ручной пересчёт, разные пайплайны) без единого источника истины.
