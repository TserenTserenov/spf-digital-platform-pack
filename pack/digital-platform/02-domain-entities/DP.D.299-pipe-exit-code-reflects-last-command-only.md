# DP.D.299 Код возврата конвейера ≠ код возврата первой команды

## Правило

Чтение вида `grep pattern file | sed 's/.../.../ ' || echo default` рассчитано на то, что если `grep` не найдёт строку, весь конвейер «упадёт» и сработает `|| echo default`. На деле код возврата конвейера в bash по умолчанию — это код возврата ТОЛЬКО последней команды (`sed`); если `sed` успешно отработал на пустом вводе (просто ничего не выведет), весь конвейер считается успешным, и фолбэк никогда не выполняется, даже когда `grep` ничего не нашёл.

## Тест

«Есть конвейер вида `cmd1 | cmd2 || fallback`, где fallback рассчитан на провал именно cmd1?» Да → без `set -o pipefail` (и то с оговорками для многозвенных конвейеров) единственный проверяемый код возврата — у последней команды.

## Фикс

Заменить конвейер одним инструментом, которому нечего маскировать (например, `awk`), либо использовать `set -o pipefail`, либо ввести промежуточную переменную для проверки первой команды отдельно.

## Применимо к

Любой bash-скрипт с конструкцией `cmd1 | cmd2 || fallback`, где фолбэк должен срабатывать на провале НЕ последней команды конвейера.
